🚀 推送到 GitHub
───────────────────────────────────────────────────────────────

【推荐方式】使用自动化脚本

  1. 打开 PowerShell
  2. 进入项目目录
  3. 运行脚本:
     .\push_to_github.ps1
  4. 按提示输入:
     - GitHub 用户名
     - GitHub Token

【手动方式】

  步骤 1: 创建 GitHub 仓库
  ───────────────────────
  • 访问 https://github.com/new
  • 仓库名: TextOnlyCompressor
  • 其他设置按需选择
  • 点击 Create repository

  步骤 2: 获取个人访问令牌 (PAT)
  ───────────────────────────────
  • 访问 https://github.com/settings/tokens
  • 点击 "Generate new token (classic)"
  • 设置:
    - Token name: TextOnlyCompressor
    - Expiration: 90 days
    - Select scopes: ✓ repo
  • 复制并保存 Token

  步骤 3: 添加远程仓库
  ───────────────────
  git remote add origin https://github.com/YOUR_USERNAME/TextOnlyCompressor.git

  步骤 4: 推送代码
  ────────────────
  git branch -M main
  git push -u origin main --tags

  步骤 5: 验证
  ──────────
  访问: https://github.com/YOUR_USERNAME/TextOnlyCompressor
