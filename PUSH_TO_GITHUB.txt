方式 1: 使用自动推送脚本（推荐）

方式 2: 手动推送（如果脚本有问题）
───────────────────────────────────

1. 在 GitHub 创建新仓库：
   https://github.com/new
   
   设置：
   • Repository name: TextOnlyCompressor
   • Description: Text compression tool with encryption
   • Public / Private (自选)

2. 复制仓库 URL（格式：https://github.com/YOUR_USERNAME/TextOnlyCompressor.git）

3. 添加远程仓库：
   git remote add origin <YOUR_REPO_URL>

4. 推送代码：
   git branch -M main
   git push -u origin main --tags

🔑 如何获取 GitHub Token

1. 访问：https://github.com/settings/tokens

2. 点击 "Generate new token (classic)"

3. 配置 Token：
   • Token name: TextOnlyCompressor
   • Expiration: 90 days
   • Scopes: 选择 ✓ repo (完全控制私有仓库)

4. 生成后复制 Token（只能看一次！）

🚀 常见问题

Q: 推送时提示 "Permission denied"？
A: 检查 Token 是否正确，或者 GitHub Token 权限是否足够

Q: 推送时提示 "Repository not found"？
A: 确保在 GitHub 上已创建同名仓库 TextOnlyCompressor

Q: Token 弄丢了怎么办？
A: 访问 https://github.com/settings/tokens 重新生成新的 Token

Q: 想改成 HTTPS 还是 SSH？
A: 脚本使用 HTTPS，如需 SSH 改为：
   git remote set-url origin git@github.com:YOUR_USERNAME/TextOnlyCompressor.git
